## The rule

Thai people do not “download another app.” They already live in LINE (~50–56M). Hits are **jobs that used to be awkward inside a group chat**, finished without leaving that chat. App-store downloads in Thailand fell ~22% in the year LINE pushed Mini App; native-app build cost rose ~9%. The winning shape is **app-in-LINE**, not another icon.

## Why ขุนทอง specifically became popular

1. **อยู่กรุ๊ปที่มีอยู่แล้ว.** Add OA → invite into the LINE group. No store listing.
2. **รับงานที่คนเกรงใจ.** ทวงเงินทำลายมิตรภาพ. บอทเป็นคนที่สาม — headline คือ “ไม่เสียเพื่อน” ไม่ใช่ “ฟินเทค.”
3. **เรียกเมื่อต้องการ.** จำเฉพาะ `ขุนทอง` / `เก็บเงิน`. นอกนั้นเงียบ. KBTG ยืนยันไม่เก็บข้อความแชท. “เห็นว่าขุนทอง read” คือระบบ LINE ไม่ใช่คนอ่าน. Trust = ไม่แอบอ่านแชท.
4. **จบงานในที่เดียว.** สรุปยอด + เตือน + จ่าย (K PLUS ในแชท / e-slip QR / เงินสดกดยืนยัน). ไม่เปิด Excel.
5. **บอทเป็นคนน่ารำคาญ.** เตือน 10:00 จนครบ. คนไม่ต้องเป็นคนน่ารำคาญ.
6. **ผลวัดได้.** 90–91% เก็บใน 1 วัน. คนแชร์เพราะมันเวิร์ก.
7. **ฟรี + ตัวละคร + ไวรัลกรุ๊ป.** นกเหรัญญิกจำง่าย. เชิญเข้ากรุ๊ปถัดไปได้ใน 10 วินาที.
8. **จังหวะโควิด / cashless.** Contactless เป็นเหตุผลสาธารณะ; งานสังคมเป็นเหตุผลจริง.

Lightsplit / Mr.Splitter ยืนยันสูตรเดียวกันในปีหลังๆ: barrier คือ “ต้องให้เพื่อนโหลด Splitwise” — บอทในกรุ๊ปชนะแอปแยกทุกครั้ง.

Luxury OA ยืนยันสูตรคนละโทน: กลุ่มกำลังซื้อสูงใช้ LINE เป็น concierge ไม่ใช่เว็บไซต์ และไม่ต้องการมาสคอตล้อเลียน.

## The popularity physics (copy these, not the bird)

| Physics | ขุนทอง / Mini App / OA | MCG Convoy |
|---------|------------------------|------------|
| Zero new app | LIFF / Mini App / OA ในกรุ๊ป | LIFF + PWA; ลิงก์ในกรุ๊ปคลับ |
| Sit in the existing graph | เชิญบอทเข้ากรุ๊ป | เชิญ MCG OA / วาง Flex ในกรุ๊ป |
| Face-saving third party | บอททวงแทนเพื่อน | MCG ถามสถานะแทนหัวขบวน |
| Wake on keyword | `#ขุนทอง` / เก็บเงิน | `#ขบวน` สถานะ / บรีฟ / แชร์ |
| Do not read the chat | Keyword-only, PDPA | ทำงานเมื่อถูกเรียกหรือตอนขบวนเปิดเท่านั้น |
| Bot nags, human doesn’t | เตือน 10:00 | เตือน 30 นาทีก่อนเป้าถึง |
| Finish in-place | จ่ายใน K PLUS | เปิดแผนที่ / เริ่มแชร์ ใน LIFF |
| Measurable proof | 90% ใน 1 วัน | เป้า: ลดข้อความ “ถึงไหนแล้ว” ในกรุ๊ป |
| Viral unit | เชิญเข้ากรุ๊ปถัดไป | Flex การ์ดหนึ่งใบในกรุ๊ปคลับ |
| Tone fit | นกการ์ตูนสำหรับนิวเจน | โทนคลับหรู — ไม่มีมาสคอต |

## Explicit non-copy

- Public pay-speed coins (ขุนทองให้เหรียญทอง/เงิน/ทองแดงคนจ่ายไว) — ชนกับกติกาห้ามแข่งความเร็ว / ห้ามประจาน.
- Mascot slapstick ในคลับหรู.
- อ่านประวัติแชทคลับ.
- ประกาศชื่อคนมาสายเข้ากรุ๊ป.
- บังคับโหลดแอปแยกแบบ LINE HERE (บทเรียน: งานเดียวกัน แอปลูก = ตาย).

## Shipped from this research

- Landing ritual **ถาม** — MCG asks so the organizer does not.
- Create trip: hide coordinates; after create, pulse the Flex card (`?share=1`) — viral unit is one group drop.
- Invite: lead with no-download + “does not read club chat” (ขุนทอง trust).
- Lobby **เหรัญญิกขบวน**: type `#ขบวน`, share status / brief / reminder Flex, T-30 nag (bot, not หัวขบวน).
- Quiet proof chip: `X / Y แชร์ · ไม่ต้องถามถึงไหนแล้ว`.
- Live HUD: share status into the group without naming anyone.
- Summary recap Flex: counts only, then “กรุ๊ปเงียบ”.
- LINE webhook: keyword-only `parseWake` — ordinary chat is ignored.
- Status / brief / remind / recap Flex: never late names, never speed.
